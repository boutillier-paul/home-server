# Glossary

### VLAN

Virtual LAN used to segment network traffic logically.

### DMZ

Isolated network zone for exposed services.

### IdP

Identity Provider used for authentication and access control.

### Zero Trust

Security model where no network location is inherently trusted.

### IaC

Infrastructure as Code — declarative infrastructure provisioning.

### GitOps

Operational model using Git as the source of truth.

### SOC

Security Operations Center capabilities such as logging and threat detection.

### Proxmox

Virtualization platform used as the primary compute layer.

### ZFS

Filesystem providing data integrity and replication capabilities.
