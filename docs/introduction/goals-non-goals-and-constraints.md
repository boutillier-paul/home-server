# Goals, non-goals & constraints

### Short-Term Goals

* Centralize core services on Proxmox
* Implement secure remote access
* Establish monitoring and observability baseline
* Create structured documentation

***

### Mid-Term Goals

* Introduce network segmentation
* Deploy identity provider
* Implement automation workflows
* Improve availability of critical services

***

### Long-Term Goals

* GitOps-driven infrastructure
* Multi-node cluster
* Disaster-resilient architecture
* Cloud-native workloads

***

### Use Cases

* Access from anywhere on any device
* Remote development environment
* Personal cloud services
* Security experimentation
* Game server hosting
* Local AI model experimentation

***

### Non-Goals

* Hyperscale performance
* Enterprise SLA guarantees
* Full replacement of public cloud providers

***

### Constraints

* Limited hardware
* Budget awareness
* Single primary operator

***
